## 3. 현재 구현 전략: 카테고리 모멘텀

### 전략 로직

```
① 카테고리 12개월 모멘텀 계산
   → 위험 상위 3개 카테고리 + 안전 상위 2개 카테고리 선택

② 카테고리 내 ETF 3개월 모멘텀 계산
   → 카테고리 내 상위 33% ETF만 선택 (월 회전율 ≥10% 확보)

③ 비중 배분
   → 위험 65% / 안전 35% 고정 (제약 70% 이하 준수)
   → 카테고리 내 선택 ETF 균등 배분

④ 거래비용: 편도 0.1%
```

### 파라미터 설정

| 파라미터 | 값 | 설명 |
|---------|-----|------|
| LOOKBACK_L | 12개월 | 카테고리 선택 기준 |
| LOOKBACK_S | 3개월 | 카테고리 내 ETF 선택 기준 |
| RISK_BUDGET | 65% | 위험자산 비중 |
| TOP_RISK | 3개 | 선택 위험 카테고리 수 |
| TOP_SAFE | 2개 | 선택 안전 카테고리 수 |
| TOP_ETF_FRAC | 33% | 카테고리 내 상위 ETF 비율 |

## 5. 문제점 분석

### 핵심 문제: 균등분산 BM보다 Sharpe가 낮음 (1.07 < 1.27)

더 복잡한 전략을 쓰는데 단순 BM보다 위험 대비 수익이 낮음 → 전략의 부가가치가 약함

### TIGER 미국S&P500에 전방위 열세

| 지표 | 우리 전략 | TIGER S&P500 | 차이 |
|------|---------|------------|------|
| CAGR | 18.2% | 21.2% | -3.0%p |
| Sharpe | 1.07 | 1.55 | -0.48 |
| MDD | -13.0% | -15.1% | +2.1%p (유리) |

### 이상 수익률 구간 존재

2025년 하반기~2026년 초 월 수익률이 비정상적으로 높음:
- 2025-10: +13.9%, 2026-01: +20.3%, 2026-04: +17.1%

특정 카테고리/ETF에 과도하게 집중된 결과로 추정 → 원인 분석 필요

## 6. 향후 개선 방향

### Phase 1: 룰 기반 전략 보완 (단기)

**① 변동성 역가중(Vol-Weighted) 도입**
- ETF 비중에 `1/σ` 가중치 적용 → 고변동성 ETF 비중 자동 축소
- 기대 효과: 변동성 감소, Sharpe 개선

**② 추세 필터 추가**
- 카테고리 12개월 모멘텀이 음수이면 해당 위험 카테고리 제외, 안전자산으로 대체
- 기대 효과: 하락장 방어력 강화, MDD 개선

### Phase 2: AI 모델 통합 (중기 — 졸업 프로젝트 연계)

현재 룰 기반(모멘텀 신호)으로 카테고리를 선택하는 부분을 **Chronos+iTransformer 하이브리드 모델**의 예측으로 대체하는 방향을 검토 중.

```
[현재]  카테고리 12개월 모멘텀 → 상위 카테고리 선택
[목표]  Chronos+iTransformer 예측 수익률 → 카테고리 랭킹 → 상위 카테고리 선택
```

- 룰 기반 모멘텀 신호는 후행성(lagging) 문제가 있음
- AI 모델은 더 다양한 피처(변동성, 거래량, 상관관계)를 반영해 선행 신호 생성 가능
