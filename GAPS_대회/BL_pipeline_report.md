## 2. 설계 철학 (v1 → v2 변경 이유)

### v1의 한계
기존 설계에서 RL 에이전트는 "AI를 얼마나 믿을지"라는 추상적인 신뢰도 파라미터(τ, Ω)만 출력했다.
이 설계의 문제점:
- RL이 가장 잘하는 **순차적 자산 배분(Sequential Allocation)** 을 활용하지 못함
- τ, Ω라는 스칼라 파라미터는 RL의 학습 신호가 너무 약함 (리워드→행동 매핑이 간접적)

### v2의 방향
**RL이 직접 자산 배분 비중 `w_RL`을 출력**하고, 이를 역최적화(Reverse Optimization)를 통해 BL 뷰로 변환한다.
이렇게 하면:
1. RL은 자신이 가장 잘하는 순차적 배분 결정을 직접 수행
2. 인간 운용역의 정성적 배분 `w_Human`도 동일한 방식으로 BL 뷰로 변환
3. Black-Litterman이 두 독립 뷰를 베이지안으로 융합 → MVO로 제약 충족

이 방식은 **글로벌 기관의 멀티-스타일 포트폴리오 결합** 기법과 동일한 원리다.

| 역할 | 담당자 | 입력 | 산출물 |
|------|--------|------|--------|
| AI 피처 생성 | 권승빈 | 카테고리별 가격 시계열 | RL State에 주입할 **AI 예측 수익률 피처** |

> BL이 이 두 의견을 수학적으로 조율하고, MVO가 대회 제약을 충족시킨다.

## 5. 수학적 핵심: 역최적화 변환

RL과 인간 운용역은 각자 "카테고리 배분 비중"을 직접 결정한다.
Black-Litterman은 "기대수익률 뷰"를 입력받으므로, 역최적화로 변환한다.

### 역최적화 공식

$$Q = \delta \cdot \Sigma_{cat} \cdot w$$

- `δ`: CAPM 역산 위험회피계수 (Layer 1에서 추정)
- `Σ_cat`: 10×10 카테고리 공분산 행렬
- `w`: 카테고리 배분 비중 (RL 또는 인간이 제안)
- `Q`: 해당 배분을 CAPM 균형으로 정당화하는 암묵적 기대수익률

**직관**: "RL이 주식 40%, 채권 60%를 제안한다면, RL은 암묵적으로 주식의 기대수익이 X%라고 믿는 것이다"라는 의미를 역산하는 공식이다.

### BL 사후 분포 공식

$$E[R] = \left[(\tau\Sigma)^{-1} + P^\top\Omega^{-1}P\right]^{-1} \left[(\tau\Sigma)^{-1}\Pi + P^\top\Omega^{-1}Q\right]$$

P = [I; I]이므로 실제로는:

$$E[R] = \left[(\tau\Sigma)^{-1} + \Omega_{RL}^{-1} + \Omega_{Human}^{-1}\right]^{-1} \left[(\tau\Sigma)^{-1}\Pi + \Omega_{RL}^{-1}Q_{RL} + \Omega_{Human}^{-1}Q_{Human}\right]$$

→ **시장 Prior + RL 뷰 + 인간 뷰**의 정밀도 가중 평균

## 7. Ω (신뢰도) 설정 전략

Ω는 각 뷰의 오차 분산이다. 작을수록 해당 뷰를 더 강하게 반영한다.

```python
# 국면 감지 (예: VIX 대용 지표 또는 최근 변동성)
recent_vol = cat_returns[-3:].std()

if recent_vol < vol_threshold:  # 평온한 국면
    Omega_RL = 0.01   # RL 강하게 신뢰
    Omega_Human = 0.05
else:  # 위기 국면
    Omega_RL = 0.10   # 인간 판단 우선
    Omega_Human = 0.01

# BL 입력
Omega = np.diag([Omega_RL] * 10 + [Omega_Human] * 10)
```

## 10. FAQ (v2)

**Q. v1과 가장 큰 차이는 무엇인가요?**
RL의 출력이 바뀌었습니다. v1에서는 RL이 "(τ, Ω) = BL 신뢰도 파라미터"를 출력했지만, v2에서는 RL이 직접 "w_RL = 카테고리 배분 비중"을 출력합니다. 이 w_RL이 역최적화를 통해 BL 뷰(Q_RL)로 변환됩니다.

**Q. AI 모델(권승빈)의 역할은 어떻게 바뀌었나요?**
v1에서는 AI 모델이 Q_AI를 직접 BL에 입력했습니다. v2에서는 AI 예측값이 RL의 State 피처로 제공됩니다. RL이 AI 예측을 보고 더 나은 자산 배분을 학습합니다.

**Q. RL이 위험자산 70% 제약을 어떻게 지키나요?**
환경 내 `_apply_risk_constraint()` 함수가 소프트맥스 출력을 변환할 때 위험 카테고리 합계가 70%를 넘으면 자동 스케일다운합니다. RL은 이 제약된 환경 안에서 학습하므로 제약 위반이 구조적으로 불가능합니다.

**Q. 인간 운용역은 어떻게 w_Human을 결정하나요?**
매크로 분석(연준 금리, 지정학 리스크, 달러 방향 등)을 바탕으로 팀 회의에서 10개 카테고리에 대한 목표 비중을 직접 결정합니다. 수식이 아닌 정성적 판단이므로 누구나 참여할 수 있습니다.
