Do Reinforcement-Learning Portfolio Results Reproduce? A Pre-registered Re-examination with the Authors' Public Code

권승빈 · [학과] · 지도교수 [이름]

공식 코드로 다시 돌린 6편 중 완전히 재현된 논문은 없었고, FinRL은 거래비용을 넣어 1/N과 비교하면 우위가 남지 않았다.

① 배경

  • 강화학습(RL)으로 주식 비중을 정하는 논문 대부분이 "시장·기존 방법보다 낫다"고 보고한다.
  • 공식 코드로 그 숫자가 다시 나오는지, 거래비용과 1/N 등가중까지 넣어도 우위가 남는지는 거의 확인되지 않았다.
  • 판정 기준을 결과를 보기 전에 고정(사전 등록)하고 공식 코드로 다시 실행했다.

② 연구 질문

Q1공개 코드로 논문의 보고 수치를 다시 얻을 수 있는가?
Q2거래비용·여러 평가 기간·여러 시드로 조건을 맞추면 1/N 등가중보다 나은가?

③ 방법 — 재현 깔때기와 판정 기준

F0 대상→ F1 공식 코드→ F2 코드 완전성→ F6 비교값→ F3 데이터→ F4 실행→ F5 계산량→ F7 재현 판정

논문은 처음 막힌 단계에서 한 번만 센다. 실행 불가·계산량 초과(시드당 10시간)는 "재현 실패"와 따로 센다.

R2 주장
"기준선보다 낫다"는 주장이 우리 실행에서도 성립하는가

⑧ 결론

  1. 공개 코드가 있어도 보고 수치가 그대로 다시 나온 논문은 없었다(6편 중 0편).
  2. FinRL의 재현된 실행도 비용을 넣고 1/N과 비교하면 우위가 사라지거나(A2C·PPO) 구분되지 않았다(DDPG·TD3).
  3. 원인의 일부는 코드 수준(비용 미부과, 비교 조건 차이)에서 확인되었다.
  4. 제언: 결과 선택 절차·시드 분포·비용 구현·1/N 비교를 함께 보고하자.

⑨ 한계

  • 표본은 무작위가 아니며 분야 전체 재현율이 아니다.
  • "미재현"은 "논문이 틀렸다"가 아니다(환경·라이브러리·비결정성).
  • F1 재확인은 1인·비맹검이다.
