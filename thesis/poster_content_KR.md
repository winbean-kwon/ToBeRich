## ① 배경 (3줄)
- 강화학습(RL)으로 주식 비중을 정하는 논문이 많고, 대부분 "시장·기존 방법보다 수익이 높다"고 보고한다.
- 그러나 공식 코드로 그 숫자가 다시 나오는지, 거래비용·단순 기준선(1/N 등가중)까지 넣어도 우위가 남는지는 거의 확인되지 않았다.
- 본 연구는 **결과를 보기 전에 판정 기준을 고정(사전 등록)**하고 공식 코드로 다시 실행했다.

## ② 연구 질문
- **Q1.** 공개 코드로 보고 수치를 다시 얻을 수 있는가?
- **Q2.** 같은 조건(거래비용, 여러 평가 기간, 여러 시드)에서 1/N 등가중보다 나은가?

## ③ 방법
**재현 깔때기 (그림 제안: 위에서 아래로 좁아지는 깔때기)**
F0 대상 적합 → F1 공식 코드 → F2 코드 완전성 → F6 비교값 → F3 데이터 → F4 실행 → F5 계산량(시드당 10시간) → F7 재현 판정
- 논문은 처음 막힌 단계에서 한 번만 센다.
- 실행 불가·계산량 초과는 "재현 실패"와 따로 센다.

**재현 판정 기준(사전 등록)**
- R1(수치): 우리 값이 보고값 허용 폭 안에 있는가. 허용 폭 = 보고값과 가장 강한 기준선 차이의 절반.
- R2(주장): 논문의 "기준선보다 낫다"가 우리 실행에서도 성립하는가.
- 둘 다 → 재현, 하나 → 부분 재현, 없음 → 미재현.

## ④ 결과 1 — 재현 깔때기 (73편)
| | 논문 수 |
|---|---:|
| 조사 표본(기존 수집 52 + 제목 검색 12 + 보충 5 + 심층 대상 4) | 73 |
| 공식 코드를 찾지 못함(저자 문의 안 함) | 34 |
| 재현 판정까지 도달 | 6 (심층 4 + 깔때기 2) |

- 큰 병목은 **공식 코드(F1)**다. 조사 표본 52편 중 31편이 F1에서 멈췄다.
- **F1 사람 재확인:** "코드 없음"으로 판정한 44편 중 **최소 5편(11%)**은 실제로 코드가 있었다. 5편 모두 논문에 링크가 없고 저자 개인 GitHub에만 있었다.

## ⑤ 결과 2 — 재현 판정 (6편)
| 논문 | 판정 |
|---|---|
| FinRL (ICAIF 2021) | 부분 재현 (4개 알고리즘 중 2개 재현) |
| Ensemble (ICAIF 2020) | 부분 재현 (수치 ✓, 우위 주장 ✗) |
| RAT (IJCAI 2020) | 부분 재현 (보고값보다 훨씬 높음, 우위 ✓) |
| MARS (AAAI 2026) | 미재현(출판 시점 코드) / 재현(저자 후속 수정 코드) |
| DeepAries (CIKM 2025) | 미재현 |
| AlphaMix+ (PRUDEX-Compass) | 미재현 (단, 논문이 밝히지 않은 선택에 따라 판정이 바뀜) |

- **완전히 재현된 논문은 없다.** 판정은 코드 판본과 논문이 밝히지 않은 세부 선택에 민감했다.
- 수치·주장 모두 [확인] 후 사용.

## ⑥ 결과 3 — 같은 조건에서 1/N과 비교 (FinRL)
- 거래비용 0.1%, 평가 기간 3개, 시드 5개로 통일해 매일 재조정 1/N과 비교했다.
- **A2C·PPO: 세 기간 모두 1/N보다 낮다**(연 약 11~12%p, 통계적으로 유의).
- **DDPG·TD3: 1/N과 구분되지 않는다**(로그 성장 차이 ±2.4%p 안에서 동등).
- 학습된 정책의 일별 수익은 1/N과 상관 **0.98 이상**이다. 사실상 1/N 근처에 머문다.

## ⑦ 결과 4 — 코드에서 발견한 것
- **거래비용이 설정대로 부과되지 않음**
  - FinRL 포트폴리오 환경: 비용을 설정해도 보상·수익에 반영되지 않는다.
  - AlphaMix+: 비용 값을 받기만 하고 쓰지 않는다.
  - DeepAries: 비중을 자주 바꿀수록 비용이 덜 부과된다(극단적 경우 설정의 약 2%).
- **보고 비교의 조건 차이(탐색적):** 한 논문(Markowitz Meets Bellman)은 공개 코드에서 제안 방법만 5종목으로 돌렸고, 기준선은 30종목이었다. 같은 5종목을 똑같은 비중으로 들고만 있어도 보고값과 거의 같은 수익(연 37.0% vs 38.7%)이 나온다.

## ⑧ 결론
1. 공개 코드가 있어도 보고 수치가 그대로 다시 나오는 경우는 드물었다(6편 중 완전 재현 0).
2. FinRL의 재현된 실행도 거래비용을 넣고 1/N과 비교하면 우위가 사라지거나(A2C·PPO) 구분되지 않았다(DDPG·TD3). DeepAries도 1/N과 구분되지 않았다.
3. 원인의 일부는 코드 수준(비용 미부과, 비교 조건 차이)에서 확인되었다.
4. 제언: 결과 선택 절차·시드 분포·거래비용 구현·1/N 비교를 함께 보고해야 한다.

## ⑨ 한계 (작게)
- 표본은 무작위가 아니며 분야 전체의 재현율을 뜻하지 않는다.
- "재현되지 않음"이 "논문이 틀렸다"를 뜻하지 않는다(환경·라이브러리·비결정성 차이).
- F1 재확인은 1인·비맹검이다.
