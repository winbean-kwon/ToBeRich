# 졸업논문 골격 (작업용 — 본문은 장별 파일로 작성)

**가제:** 강화학습 포트폴리오 정책의 성과 검증: 평가 점검과 공식 공개 코드의 재평가

**한 문장 요지(안):** 출판된 RL 포트폴리오 방법 세 편(FinRL, AlphaMix+, DeepAries)을 공식 코드로 사전 등록 기준에 따라 재실행했다. 보고 수치는 일부만 재현되었고, 재현된 실행의 성과는 같은 기간 1/N 등가중과 구분되지 않았다. 세 구현 모두 정책 매개화가 가중치를 1/N 근방에 묶고, 둘은 설정된 거래비용을 부과하지 않았다.

> 집필 규칙: 결과·방법만 표준 학술 문체로 쓴다. 커밋 해시, 실행 횟수, 감사 경위는 넣지 않는다. 탐색적 결과는 본문에 표시한다. 보고 순서는 판정 → 해석 → 한계다.

## 1장 서론
- 문제: RL 포트폴리오 논문의 보고 우위와 평가 관행(무비용 평가, 단일 시드, 결과 선택 미기술)
- 연구 질문: (Q1) 공식 코드로 보고 수치·주장이 재현되는가. (Q2) 통일 프로토콜에서 1/N 대비 우위가 유지되는가.
- 기여(과장 금지):
  - (i) 공식 코드 세 편의 사전 등록 재현·재평가
  - (ii) 코드 수준의 원인 기술: 비용 미부과, 1/N 근방으로 묶는 매개화, 균등 초기화
  - (iii) 자체 계층 RL 사례에서 평가 시작 상태 효과
- 주장하지 않는 것: "논문 수치가 틀렸다", 표본 밖 일반화, 동등성
