# T3 O6 — 결정적 예측 변형(후속 실험 사전 등록)

작성 2026-10-29, 실행 전 커밋. O2 결과(`notes/finrl_t3_o2_result.md`) 3장 탐색적 진단의 후속이다.
O2 판정(공식 설정 deterministic=False)은 바꾸지 않는다. 이 실험의 결과는 O2를 대체하지 않고 "예측 설정 변형"으로 따로 보고한다.

## 1. 질문
A2C·PPO의 O2 소실이 (i) 공식 예측의 표본 추출 회전율 때문인지, (ii) 정책이 학습되지 않았기 때문인지 가른다.
DDPG·TD3는 SB3에서 predict가 deterministic 인자와 무관하게 같은 행동을 내므로 대상이 아니다.

## 2. 실행
- 대상: A2C, PPO. 창 W0·W1·W2, 조건 (a)·(b), 시드 0–4 → 60회. 나머지 설정(데이터, 학습 기간, 하이퍼파라미터, timesteps, torch 스레드)은 O2와 같다.
- 학습은 O2와 같은 시드로 다시 한다. 학습 직후 (1) 공식 예측(deterministic=False, 예측 직전 np/torch 시드 고정 — O2와 동일)과 (2) 결정적 예측(model.predict(deterministic=True))을 같은 모델로 모두 저장한다.
- 출력 `replication/finrl_t3/o6/{algo}_{창}_{조건}_s{시드}_{sto|det}.csv`. 모델 파일은 `.t3env/models/`(저장소 밖)에 둔다.
- 평가는 O2와 같은 `u1_returns`(현금 시작, U1 비용)와 같은 기준선이다.

## 3. 판정(실행 전 고정)
- **E1 재학습 동일성(점검):** 60회 각각 sto 가중치와 O2/O1 원 CSV의 최대 절대 차이 ≤ 1e−8이면 통과. 실패한 실행 수를 보고하고, 실패가 있어도 E2·E3은 계산하되 "원 실행과 다른 모델" 표지를 붙인다.
- **E2 PPO 미학습 예측:** 조건 (b) PPO det 15회 중 ≥12회에서 모든 날 max_i |w_i − 1/28| < 0.001이면 "PPO 미학습 진단 지지", ≤3회면 "지지 안 됨", 그 밖은 "판정 불가".
- **E3 결정적 예측 O2 판정:** 조건 (b), c = 0.001, 매일 등가중 대비, O2와 같은 Δ·창 분류(4/5 시드)·대상 분류(유지/소실/불확정)·'차이 작음' 규칙을 det 가중치에 적용한다. A2C·PPO 각각 보고.
- 해석 규칙(고정):
  - E3에서 A2C가 소실이 아니면(유지 또는 불확정) "A2C 소실은 예측 설정에 의존한다"고 적는다. 소실이면 "결정적 예측에서도 소실".
  - E2 지지이면 PPO 소실을 "학습되지 않은 정책 + 표본 추출 비용"으로 적는다.
- 2차(판정 아님): 조건 (a) det의 같은 계산, W0 조건 (a) det의 O1식 연수익(R1·R2 기준 대조), det 평균 회전율, c = 0 Δ.

## 4. 한계(미리 적음)
- 결정적 예측은 원 논문·튜토리얼 설정이 아니다. 원 방법의 성과로 보고하지 않는다.
- 같은 창 3개·시드 5개를 다시 쓴다. 새 데이터가 아니므로 O2 진단의 독립 검증이 아니라 같은 모델의 다른 예측 방식 비교다.
