# 사전 등록 초안 — RL 포트폴리오 환경의 참조 명세·적합성 테스트와 영향 측정

> 상태: **초안(커밋 전 검토 중)**. 이 문서의 기준은 감사·실험을 시작하기 전에 커밋하고, 이후 결과를 보고 바꾸지 않는다. 바꿔야 하면 바꾼 이유와 시점을 따로 기록하고 해당 판정은 '탐색적'으로 강등한다.

## 0. 연구 질문
- Q1. 공개 RL 포트폴리오 구현은 설정한 거래비용을 실제로, 올바른 시점에, 선언한 비용 모형대로 부과하는가? 평가 시작 보유는 무엇이며 정책이 그것을 관측하는가?
- Q2. 비용이 부과되지 않은 구현에서, 비용을 올바르게 적용하면 출판된 비교 결론(베이스라인 대비 우위)이 유지되는가? 비용을 넣고 다시 학습하면 회전율과 결론이 어떻게 바뀌는가?

기여의 형태: (1) RL 포트폴리오 환경의 참조 명세(보상·비용 시점·시작 보유), (2) 어떤 구현에도 어댑터로 붙이는 적합성 테스트, (3) 공개 구현 적용 결과, (4) 영향 측정. 불변식과 참조 구현으로 감사한다는 발상은 Yin et al. 2026(arXiv 2603.20319, 일반 백테스트 엔진 대상)에서 가져왔음을 밝힌다.

## 2. 참조 명세
기호: 보유 직후 가중치 w⁺_{t−1}, 가격 변동 후 드리프트 가중치 w'_t = w⁺_{t−1}⊙y_t / (w⁺_{t−1}·y_t), 새 목표 w_t, 비용률 c, 회전율 τ_t = Σ_i |w_{t,i} − w'_{t,i}|(현금 제외 여부는 구현의 선언을 따름).
- 비용 시점: 리밸런싱이 일어난 스텝의 가치 변화에 그 리밸런싱 비용이 반영되어야 한다.
- 비용 모형: 각 구현이 **스스로 선언한** 모형(문서·논문 식·코드 주석)을 참조값으로 쓴다. 선언이 없으면 비례 근사 V⁺ = V·(1 − c·τ)를 쓴다. TRF(Jiang 2017 식)는 반복 해를 참조값으로 계산한다.
- 시작 보유: 평가 첫 스텝 직전의 보유와, 정책이 직전 보유를 관측하는지를 기록한다(옳고 그름 판정 아님, 기술).

## 3. 적합성 테스트 (각 구현에 어댑터로 적용, 정책 대신 스크립트 행동열 사용)
| ID | 검사 | 통과 기준 |
|---|---|---|
| T1 무거래 | 매 스텝 목표 = 드리프트 가중치 | 가치 변화가 가격만으로 계산한 값과 상대오차 1e−6 이내 |
| T2 비용 크기 | 현금→등가중, 등가중→단일 종목 등 회전율을 아는 행동 3종 | 측정 비용 / 참조 비용 ∈ [0.9, 1.1] |
| T3 설정 반영 | 같은 행동열을 c=0과 c=설정값으로 실행 | 최종 가치가 다르면 통과. 같으면 **'설정됐지만 부과 안 됨'** |
| T4 시점 | 리밸런싱 1회만 하는 행동열 | 비용이 그 스텝에 반영되면 통과, 다음 스텝이면 '지연', 반영 없으면 T3 실패로 귀속 |
| T5 시작 보유 | reset 직후 보유, 관측 포함 여부, 학습·평가 reset 동일 여부 | 기술 기록(판정 없음) |
| T6 벤치마크 비용 | 저장소가 제공하는 베이스라인(EW, buy-and-hold 등)에 같은 비용이 붙는가 | 정적 읽기로 기록(실행 가능하면 T3 방식으로 확인) |

## 4. 두 방법 감사 절차
1. **정적 읽기 먼저**: 대상별 T2~T6 예상 판정을 코드 읽기만으로 표에 적고(행 번호 포함) **커밋**한다.
2. 그다음 동적 테스트를 실행한다.
3. 보고: 두 방법의 일치 개수, 불일치는 원인(정적 오독/어댑터 오류/테스트 결함)을 밝혀 기록. 동적 결과를 우선하되 어댑터 오류 가능성을 함께 적는다.
4. 정상으로 나온 구현도 그대로 보고한다.

## 5. 영향 측정 (C)
대상: (1) FinRL 포트폴리오 배분 공식 튜토리얼(`StockPortfolioEnv`, 튜토리얼의 알고리즘·기간 그대로), (2) PRUDEX AlphaMix+(저장소에 실행 스크립트가 있는 설정 그대로). 시드 5개(0~4). 비용 적용은 2장 명세의 비례 모형, c = 각 저장소 설정값(0.001).
조건: (i) 무비용 학습·무비용 평가(원래) (ii) 무비용 학습·비용 평가 (iii) 비용 학습·비용 평가.
베이스라인: 매 스텝 등가중 리밸런싱, buy-and-hold 등가중 — (ii)(iii)에서 같은 비용 적용.

| 가설 | 기준 |
|---|---|
| H0 재현 | (i)의 결과를 원 논문/튜토리얼 보고값과 비교해 차이를 보고(판정 아님). 보고값과 부호가 다르면 이후 결론에 그 사실을 함께 적는다 |
| H9 결론 역전 | 방법×시스템마다: (i)에서 '방법 > 최선 베이스라인'이 시드 ≥4/5에서 성립하던 것이 (ii)에서 시드 ≥4/5로 '방법 < 최선 베이스라인'이 되면 역전. 역전 개수 / (i)에서 우위였던 개수 를 보고 |
| H10 학습 회복 | (iii)에서 '방법 > 최선 베이스라인'이 시드 ≥4/5면 회복 |
| H11 회전율 | (iii) 평균 회전율 / (i) 평균 회전율의 시드 중앙값 < 0.5 이면 '비용 학습이 회전율을 줄임'. 단 정책이 직전 보유를 관측하지 않는 FinRL `StockPortfolioEnv`는 원리상 회전율 조절이 어렵다는 점을 미리 적어 두고 그대로 판정 |

EarnMore: 무료 Colab 자원으로 전체 재학습이 어려우므로 공개 설정으로 1회 학습 후 (ii)만 측정하고, 축소판임을 명시한다(가설 판정에서 제외, 기술 보고).

## 6. 책임 있는 공개
