## (1) Margin Trader (조건 P, 시드 0–4)
- 입력: 서버 F7x 출력(읽기만, scratchpad로 복사) — 시드별 `trade_result.csv`·`perf_stats_trade.csv`, env가 쓰는 `data.csv`(sha256 7b824748…)의 2020–2023 행.
- 등가중: 28종목, 2020-05-01~2023-04-27(753일), env가 가격으로 쓰는 `close` 열, 매일 재조정, 현금 시작. 결측 가격 0칸.
- c = 0.001: `trading_margin_a2c.py:95`(`buy_cost_list = sell_cost_list = [0.001] * stock_dimension`). `marginEnv.py`에서 롱은 현금에 (1±c)로(123·187행), 숏은 credit에서 c로(238·281행) 한 번 부과된다. 롱 매매 때 `state[2]`(롱 자기자본)도 c만큼 줄이지만 `_update_state`가 현금+시가−대출로 다시 계산하므로 계좌 가치에는 한 번만 반영된다(30일마다의 `_update_loan`은 줄어든 값을 쓴다 — 계좌 가치에 미치는 간접 효과는 확인하지 않음).

| | Sharpe |
|---|---|
| 등가중(c=0.001) | 0.717 |
| 등가중(0) | 0.734 |
| 시드 0~4 | 0.035 / 0.155 / 0.030 / 0.404 / 0.117 |
| 평균 − 등가중(c) | −0.569 |

- **등가중(c) 초과 0/5** → 사전 등록 해석: "실행 대부분이 같은 비용의 등가중을 넘지 못했다."
- 냉정한 해석: 다섯 시드 모두, 최고 시드(0.404)도 같은 비용 롱 전용 등가중에 못 미친다. 다만 Margin Trader는 보고값 자체가 재현되지 않은 방법이라(탐색적 미재현, 평균 0.148 대 보고 0.793) 이 비교는 "재현 실패한 실행이 단순 기준에도 못 미쳤다"는 정보를 더할 뿐이다. 보고값 0.793도 이 등가중(0.717)보다 0.076 높은 수준이다(같은 데이터가 아니므로 참고만).

AAPL·MSFT 2020-01-02 행에서 `close` = 시가(74.06 / 158.78), `high` = 종가, `low` = 고가, `open` ≈ 수정 종가다. yfinance 새 판의 열 순서(Adj Close, Close, High, Low, Open, Volume)를 FinRL 0.3.6 YahooDownloader가 위치로 이름 붙인 결과로 추정한다(shim `funnel_f4_yf_shim.py`는 다단 열만 펴고 순서는 바꾸지 않음). 그렇다면 F7x Margin Trader는 env 가격·지표를 시가(미수정)·뒤섞인 고저가로 학습·평가했고, 같은 shim을 쓴 다른 FinRL 계열 실행(F4 맥 등)도 같은지 확인해야 한다. 이번 등가중은 env와 같은 `close` 열을 썼으므로 비교 자체는 같은 가격 위에서 이뤄졌다.
