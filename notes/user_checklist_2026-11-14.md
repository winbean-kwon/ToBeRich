# 사용자 확인 목록 (2026-11-14)

계산은 Claude가 따로 진행한다. 아래는 원문·메일함 등 **사용자만 할 수 있는 확인**이다. 위에서부터 할수록 막힌 작업이 풀린다. 결과는 각 항목의 "기록할 곳"에 적고 Claude에게 알려 주면 이어서 진행한다.

## 1. 내일 필수 — 통계 v2 범주 판정을 막고 있음 (5분)
- **무엇:** FinRL(ICAIF 2021) 원문 7쪽 Table 3.
  - `Sharpe ratio` 행의 각 칸에는 숫자가 두 개 있다. 뒤 숫자가 포트폴리오 배분 값인지 본다. 그 값이 A2C 2.36 / PPO 2.11 / DDPG 2.21 / TD3 2.28이고 DJIA가 2.02인지 확인한다.
  - 같은 표의 `Annualized return` 행에서 DDPG 36.01%, DJIA 32.84%도 확인한다.
- **기록할 곳:** `notes/claim_ledger.md` A9·A10·A11의 `결과` 칸.
- **이후 진행:**
  - 판독이 맞으면 Claude가 δ_SR = 0.09로 확정하고 범주 판정과 결과 노트를 쓴다.
  - 판독이 다르면 그 값으로 서버 경계 점검을 다시 돌린다(약 1시간 15분).

## 2. Margin Trader 탐색적 F7 여부 결정 (5분)
- **무엇:** Margin Trader(ICAIF 2023) 원문 Table 2.
  - 우리가 지금 갖고 있는 보고값은 PPO 행이다(Long AR 30.9%, SR 1.046; DJI SR 0.790).
  - 저자 공개 스크립트는 A2C만 돌린다. 그래서 Table 2에 **A2C 행이 있는지**, 있다면 시장 설정이 Long인지 Long&Short인지와 AR·SR 값을 적는다.
- **기록할 곳:** 이 파일 아래 칸, 또는 Claude에게 직접 말하기.
- **이후 진행:**
  - A2C 행이 있으면 사전 등록과 반박 심사를 거쳐 맥에서 5회 실행한다(약 15분). 결과는 본 표와 분리해 "탐색적(프로토콜 3.3 밖)" 한 줄로만 적는다.
  - A2C 행이 없으면 하지 않는다(F7을 정의할 수 없음).
- 결과: A2C 행 ___ / 설정 ___ / AR ___ / SR ___

## 3. 대장 A절 — 논문 보고값 원문 대조 (1~2시간, 11/25 집필 전)
- **무엇:** `notes/claim_ledger.md` A1~A22.
  - 행마다 검색어, 쪽, 표 위치, PDF 링크가 적혀 있다.
  - PDF에서 검색어로 찾아 값이 맞는지 보고 `결과` 칸에 `일치(날짜)` / `불일치: 원문 값 …` / `원문에 없음` 중 하나를 적는다.
- **왜:** 논문 표 2(재현 판정)의 보고값과 허용 폭이 모두 여기서 나온다. 대장 규칙상 사용자가 채운 행만 논문에 쓸 수 있다.

## 4. F1 재확인 시트 — 54편 (1~2시간)
- **무엇:** `notes/lit/f1/f1_recheck_sheet.csv`.
  - 논문마다 공식 코드가 있는지 판정해 채운다. 사전 등록은 `notes/f1_recheck_prereg.md`.
  - 다 채운 뒤 `python3 replication/f1_recheck.py score`를 실행한다.
- **왜:** 논문 표 1(깔때기)의 "공식 코드를 찾지 못함" 38편이 이 결과에 따라 바뀐다.
