> 상태: **확정(2026-11-05 커밋).** 반박 심사 1회 반영본. F0 이후 단계의 판정과 S-Q 검색을 시작하기 전에 고정한다.
> 결과를 본 뒤 단계 정의를 바꾸지 않는다. 바꿔야 하면 이유·시점을 적고 해당 단계를 '탐색적'으로 강등한다.
> 참고한 형식: Ferrari Dacrema et al. (RecSys 2019; TOIS 2021). 그들은 고정 학회·연도의 proceedings를 전수 조사하고 저자에게 문의했다. 이 연구의 표본은 그만큼 체계적이지 않다(1장). 재현 판정은 대상별 사전 등록(v3, T4 등)을 따른다.

## 0. 질문과 주장 범위
**질문.** 표본에 든 RL 포트폴리오 논문 중 공개 코드로 보고 수치 재현을 시도할 수 있는 것은 몇 편이고, 시도한 것은 어떻게 판정되는가.

**주장하지 않는 것.**
- 분야 전체의 재현율. 정적 층(F0~F3, F6)은 표본의 기술이고, 실행 층(F4, F5, F7)은 "시도 n편"으로만 쓴다.
- "실행 불가 = 논문이 잘못됐다." 실행 불가는 우리의 환경·시간 제약 안에서의 결과다.
- 코드 없음·실행 불가·한도 초과·미시험을 '재현 실패'로 세는 것. 재현 실패와 분리해 적는다.

## 2. 단계(앞 단계 통과만 다음으로, 첫 탈락 사유만 집계, 나머지는 비고)
| 단계 | 질문 | 통과 기준 | 근거로 남길 것 |
|---|---|---|---|
| **F0** 대상 | 방법을 제안하고 표본 외 수치를 보고하는가 | 다자산 RL 방법 제안 + 표본 외 수치. 플랫폼·서베이는 탈락. 원문을 못 구하면 "원문 미확보" | 원문 위치 |
| **F1** 공식 코드 | 저자의 코드가 공개돼 있는가 | 본문·저자 페이지가 가리키거나 저자 계정의 저장소이고 확인일에 열림 | URL, 확인일. "링크 사망", "제3자만", "찾지 못함(날짜)", "문의 무응답", "찾지 못함(문의 안 함)" 구분 |
| **F2** 코드 완전성 | 학습·평가 진입점이 있는가 | 학습·평가 스크립트와 환경·보상 코드 | 경로. 저자가 부분 구현이라 밝히면 "저자 명시 부분 구현"으로 멈춤. 비고: 논문–코드 불일치(설정값, 튜토리얼 조합 등) |
| **F6** 비교 대상 | 비교할 보고 수치가 있는가(정적 판단이라 앞에 둠) | 평가 기간과 수치가 표·본문에 있고 공개 데이터와 대응. 그림만 있으면 "그림 판독" | 표 번호, 값 |
| **F3** 데이터 | 저자 요청·유료 구독 없이 원 데이터를 얻는가 | 유형 표기: **번들 / 공개 경로 동일 스냅샷 / 재수집(원본과 다를 수 있음) / 구축 필요**. 유형별로 따로 집계하고 합치지 않는다 | 경로, 크기 |
| **F4** 실행 | 허용 수정만으로 최소 학습·평가 경로가 도는가 | 실제 실행으로만 판정. 코드만 읽은 판단은 "미시험(정적 의심)" | 환경, diff, 오류 로그, 작업 시간 |
| **F5** 계산 | 시드당 한도 안에 드는가 | 측정 장치와 함께 환산 시간 표기. 10시간 초과는 실패가 아니라 "한도 초과" | 측정값, 장치 |
| **F7** 판정 | 재현되는가 | 대상별 사전 등록에 따라 재현 / 부분 재현 / 미재현 / 판정 불가 | 결과 노트 |

### 2.1 코드 버전 규칙
논문 초판 직전 커밋을 주 대상으로 하고 현재 HEAD와의 차이를 기록한다. 출판 후 동작 변경은 "출판 후 수정"으로 표시한다. 초판 직전 커밋이 없으면(저장소가 초판 이후 생성) 가장 이른 커밋을 쓰고 표시한다.

### 2.2 F4 규칙
- **성과 비노출:** 평가 경로는 학습 데이터 조각(날짜만 평가 기간으로 바꿈)으로 시험하고 지표를 열지 않는다. 노출되면 날짜와 함께 기록한다.
- **상한:** 대상당 벽시계 작업 8시간, LLM 사용을 명시한다. 전체 F4 예산은 벽시계 40시간이다.
- **환경:** Colab, 맥, conda를 모두 시도한다. TF1 전용도 동일하다.
- **허용 수정:** v3 2.3과 T4 사전 등록 2.2의 1~5번으로 통일한다.

### 3.2 저자 문의(사용자 결정 사항)
외부 발송이므로 사용자가 결정한다. 하면: F1 미통과 전 논문의 교신저자에게 동일 문구로 2026-11-07까지 보내고 14일 기다린다(선행 연구의 30일보다 짧음을 명기). 무응답은 "문의 무응답"이다. 하지 않으면: 그 논문은 모두 "찾지 못함(문의 안 함)"으로 적고 코드 부재로 단정하지 않으며, 이 점을 한계로 적는다. 일부만 문의하면 대상과 선택 이유를 적는다.

### 3.3 실행 층의 순서(성과와 무관, 고정)
1. T1~T4를 제외하고 F0~F3, F6을 통과한 논문을 대상으로 한다. **S56 먼저, 보충 표본과 S-Q 신규는 그 뒤.**
2. 각 집합 안에서: ① 학회·학술지 본 논문 먼저, 워크숍과 저널 레퍼런스 없는 arXiv는 나중 ② 연도 최신순 ③ 저장소 크기 작은 순.
3. **F4·F5를 통과한 논문은 이 순서대로 F7에 넣고 건너뛰지 않는다.** F7은 순서상 최대 2편이다. 2편이 차면 이후 논문은 F4까지만 진행한다.
4. F7 시작 마감은 2026-11-10이다. 정적 층이 끝나기 전이면 그때까지 확정된 순서로 시작한다. 시작하지 못한 논문은 "미시험(일정)"이다.
5. F4 예산이나 11-24에 멈추면 멈춘 위치를 보고하고 이후 논문은 "미시험(일정)"이다. F7 사전 등록은 시험 실행 성과를 보지 않은 상태에서 쓴다.

## 5. 알려진 한계

- Ferrari Dacrema의 '재현 가능'은 코드·데이터 가용성 중심이고(요약 도구로 확인, 인용 전 원문 재확인 필요), 이 연구의 F7은 수치까지 판정한다. 수치를 직접 비교하지 않는다.
