## 2. 재측정 사전 등록 (실행 전 고정, 이 커밋)
**이유:** 1회의 torch 이탈은 노트북 오류다. 시간 초과를 본 뒤 결정한 재측정이므로, 아래 규칙을 어느 방향이든 그대로 적용한다. 재측정은 이것으로 끝이다.

**환경:** torch 1.13.0+cu117, torchvision 0.14.0+cu117, torchaudio 0.13.0+cu117(README 그대로). 설치 칸에서 버전과 CUDA를 확인하고 다르면 멈춘다. 장치는 1회와 같은 T4만 인정하고 다르면 실행하지 않는다. 나머지 설정·시드 42·2 에피소드·시험 구간은 1회와 같다.

**판정 값:**
- A = `(시작 + 2번째 × 2000) / 3600`. 1회와 같은 식이고 27.58을 대체한다. 빨라지든 느려지든 대체한다.
- B = `(시작 + (13.24 × 사이클당 학습 초 + 평균 검증 초 × 542/365) × 2000) / 3600`. 공식 분할 0의 환산이다. 13.24는 공식 분할 0의 학습 거래일 2603일과 공식 무작위 시작 규칙으로 모의한 에피소드당 평균 사이클 수(측정값 아님)이고, 542/365는 검증 일수 비율이다.

**판정:**
1. A > 10시간: F5 "한도 초과"(T4). 다음은 PPN.
2. A ≤ 10시간이고 B > 10시간: F5 "한도 초과"(T4). 시험 구간이 공식 분할보다 짧아 A만으로 통과시키지 않는다. 다음은 PPN.
3. A ≤ 10시간이고 B ≤ 10시간: F5 통과. 단 시험 경로 문제가 남으므로 F7에 넣기 전에 멈추고 사용자에게 보고한다.
4. README 환경에서 설치·실행이 실패하면: 허용 수정 범위에서만 고치고 이탈을 적는다(대상당 벽시계 8시간 안). 끝내 안 되면 "README 환경 실행 실패"를 적고 F5 값은 27.58(torch 2.8.0 이탈 표기)로 둔다. 다음은 PPN.

**판정에 쓰지 않는 탐색적 기록:** 에피소드별 사이클 수·학습 초·검증 초, GPU 이용률, CPU 시간 비율, 분할 1·2의 환산, 모의 사이클(시드 42 기준 12, 9)과 실측의 일치 여부.

**실행 전 실패 기록(규칙 4, 시간 측정 전):** 11-05 설치 단계 `importcheck`에서 실패. qlib 받기가 네트워크 시간 초과로 실패해 qlib→jupyter→ipython→matplotlib-inline 의존성이 빠졌고, Colab 커널의 `MPLBACKEND=module://matplotlib_inline.backend_inline`이 하위 프로세스로 넘어가 matplotlib import가 실패한 것으로 판단한다. 보강: `MPLBACKEND=agg`, pip 시간 초과 120초·재시도 5회. 공식 코드·설정·판정 규칙은 바꾸지 않았다. 공식 코드의 외부 import 17종을 점검했고, qlib 없이 빠지는 것은 없다고 판단한다. `hfai_env`는 `try`로 감싸여 있어 없어도 된다. 1회 측정 때는 qlib이 설치되어 있었으므로 이번에 qlib이 빠지면 환경 차이로 적는다.
