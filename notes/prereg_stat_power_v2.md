> **실행 순서와 봉인(δ_SR 미정 때문에):** (1) 보정 점검 `calib`(크기: ΔSR·ΔG, 경계: ΔG) → (2) 본 계산 `main`(점추정·구간·p·MDE·ρ만, 범주 없음). `out/main.json`은 δ_SR가 `replication/stat_power/delta_sr.json`으로 커밋될 때까지 **열지 않고 요약도 출력하지 않는다**(사용자·Claude 모두). 생성 직후 `out/main.sha256`을 커밋해 이후 변경이 없음을 남긴다. `calib.json`·`main.json`에는 실행 커밋 해시와 입력 파일 sha256이 들어간다. (3) δ_SR 커밋 후 `calib_srb`(ΔSR 경계) → `categorize`(범주·Holm·O2 대조) → 결과 노트. `calib.json`(귀무로 변환한 합성 자료의 기각률)은 효과 크기 정보를 담지 않으므로 (2) 전에 보고할 수 있다.

## 0. 성격과 한계(먼저 적는다)
- **이미 판정이 난 재현 결과의 재분석이다.** O1·O2 판정, 각 실행의 점추정, 그리고 FinRL O2의 보조 통계(시드별 LW 샤프 검정: A2C·PPO 5/5 유의, DDPG·TD3 0/5; MDE80 1.5~5.4%p, `notes/finrl_t3_o2_result.md` 26행)는 이미 공개돼 있다. 따라서 맹검이 아니고, 결과의 상당 부분은 예측 가능하다(A2C·PPO 열위, DDPG·TD3 비유의). 목적은 기존 판정에 신뢰구간과 검출력 정보를 붙이는 것이다.
- O1·O2 판정은 바꾸지 않는다. 새 데이터·미지 구간·재학습을 쓰지 않는다.
- 표준 절차다(Ledoit & Wolf 2008; DeMiguel 외 2009). 직접 선행: Kruthof & Müller(FRL 2025), Aarnio(2025 석사논문, LW CBB로 PPO·A2C·DDPG 대 1/N). 투고판에서는 부록 표 1개의 위상이다.
- **순환 논증 경계:** FinRL 정책은 매개화 상한·낮은 active share 때문에 기준선과 상관이 높을 것이 예상된다. "동등/비우월"이 나오면 그것은 이 구조로 예측되는 결과라고 함께 적는다.

## 2. 지표
- 주 지표 ΔSR = SR(정책) − SR(기준선), SR = 일별 단순 순수익 평균/표준편차 × √252, 무위험 0.
- 보조 지표 ΔG = 연율 로그 성장 차이(%p/년, O2와 같은 지표).
- ρ = 정책·기준선 일별 수익 상관(실행별 보고).

## 3. 검정
- **실행별(보조):** Ledoit & Wolf(2008) 스튜던트화 원형 블록 부트스트랩. ΔSR 표준오차는 델타 방법 + HAC(Parzen 커널, Andrews 자동 대역폭, **prewhitening 없음**), 부트스트랩 표본의 SE는 Götze–Künsch 블록 기반. p 값은 LW 2008 식 (9)의 정의(스튜던트화 통계량의 양측 부트스트랩 p). 블록 b = 20(주, v3 `prereg_reeval_v3.md` 112행의 20일 블록과 일치시키기 위함), 민감도 b = 5·10. B = 4,999, 난수 시드 20261113.
- **알고리즘 단위(주 판정, A7):** 통계량 = 3창 × 5시드 평균 ΔSR(ΔG도 같음). 창은 층으로 두고 각 창 안에서 날짜 블록을 시드 전체와 기준선에 공통으로 원형 재표본한다(시드는 고정 → **"시드 조건부" 구간**으로 표에 명시). 델타 방법 SE로 스튜던트화한다(A5). 보조로 2단계 부트스트랩(시드 재표본 → 날짜 블록 재표본)의 백분위 구간을 같이 낸다.
- **창 단위 12개(4 알고리즘 × 3창):** 보조. 같은 절차를 창 하나에 적용.
- **MDE:** (z_{0.975} + z_{0.8}) × SE_boot. 참고로만 보고하고 범주에 쓰지 않는다(A2). Memmel 보정 Jobson–Korkie 해석식은 "iid 하한"으로 표시하거나 뺀다.

- **구현 세부(코드와 같음):** SR은 모집단 적률(ddof = 0), 각 층의 첫 행(현금 시작 자리, 수익 0)은 뺀다. ΔG = 252·mean(log(1+r_p) − log(1+r_e))로, O2의 (252/N)·Σ(행 0 포함)와 소수점 수준에서 다를 수 있다. 부트스트랩 표본은 층마다 l = ⌊T/b⌋ 블록(T′ = l·b; MDE의 sd(θ*)는 T′ 기준이라 T = 252일 때 약 2.5% 크다). 영향 함수 φ = 층마다 실행 평균 IF(정책) − IF(기준선), Var(θ̂) = (1/S²)Σ_s Ω_s/T_s(창 독립 가정). Andrews AR(1) 계수는 ±0.97로 자른다. 2단계는 층마다 실행 열을 복원 추출한 뒤 같은 날짜 블록 재표본. 난수는 [20261113, crc32(대상·지표·b)]로 대상마다 고정. 실행별 대상의 단측 경계·TOST 구간도 같은 a1 = α/4로 계산해 기록만 한다(범주 없음).
- **합성 자료 사전 점검(실데이터 미사용, 이 문서 확정 전에 수행):** T = 250 iid 정규 쌍(상관 0.9, 귀무 모집단에서 추출), B = 499, 1,000회에서 양측 α = 0.05 기각률은 b = 20일 때 ΔSR 0.026·ΔG 0.017, b = 5일 때 0.043·0.047이었다. 즉 주 블록 b = 20은 짧은 단일 창(블록 12개)에서 **보수적**일 것으로 예상된다. 반박 심사의 합성 모의(400회)에서는 실행 단위 0.005–0.03, 알고리즘 단위(창 3개, 블록 36개) 0.03–0.053이었다. 원인은 원표본 t를 HAC(iid에 가까우면 대역폭이 작아 정규에 가까움)로, t*를 블록 l개의 Götze–Künsch 분산(자유도 약 l − 1의 두꺼운 꼬리)으로 스튜던트화하는 데서 오는 fixed-b 문제로 본다. b = 20은 v3 정합 때문에 유지하고 §5의 판정 규칙을 이 사실에 맞춰 정했다.
- **LW 2008과 다른 점(공개):** LW는 원표본 HAC에 prewhitening한 QS 커널(Andrews–Monahan 1992)을 쓰고 블록 크기 b를 보정 알고리즘(Algorithm 3.1)으로 고른다. 이 연구는 Parzen·prewhitening 없음, b = 20 고정(v3 정합)을 쓴다. 그만큼 검출력 일부를 포기한다.
- **실행 전에 예측되는 것(사후 해석 방지):** ① δ_SR 후보값 0.09(§9-3)는 1년 창 3개에서 나올 ΔSR 표준오차보다 훨씬 작다. 따라서 ΔSR의 "동등"·"비우월"은 사실상 나올 수 없다. ② b = 20은 보수적이고 b = 5는 명목 수준에 가까우므로 "블록 크기 민감" 표시가 나올 가능성이 높다.

## 4. 판정 범주(F 알고리즘 단위, 지표별) — 결정 1: **안 2(비우월 + TOST)**
- 다중성: 알고리즘 단위 4개 검정에 지표마다 Holm(α = 0.05). 비우월성·동등 경계 검정은 Bonferroni α/4 = 0.0125 단측(TOST 구간 = 1 − 2·0.0125 = 97.5%).
- 범주 우선순위: 우위·열위 → 동등 → 비우월 → 판정 불가(아래 표의 위에서부터 처음 맞는 것). 유의한 열위이면서 동등 구간 안에 드는 경우는 "열위"로 적고, TOST 결과를 함께 표기한다.
- "비우월"은 "δ 이상의 우위가 배제됨"이라는 뜻으로만 쓴다(정책이 기준선보다 나쁘지 않다는 뜻이 아니다).
- δ: δ_G = ln(1.3601/1.3284) = **0.02358(2.36%p/년, 연율 로그 성장)**. 원 논문의 최소 보고 우위(DDPG 36.01% − DJIA 32.84%, Table 3 "Annualized return", 대장 A9·A11)를 우리 지표 단위로 환산한 값이다. pyfolio annual_return이 복리 연수익(CAGR)이라는 가정에 근거한다(919be84판·v2 초안의 3.17%p는 단위가 맞지 않아 관대한 쪽으로 치우쳤다). δ_SR = §9-3.

- 블록 민감도: b = 5·10·20 중 범주가 하나라도 다르면 "블록 크기 민감"으로 표시. 주 범주는 b = 20.
- O2 판정(창별 4/5 시드 규칙)과 대조표를 낸다. 불일치는 그대로 보고하고 O2를 바꾸지 않는다.

## 5. 보정 점검(결과 해석 전에 먼저, A6)
- 대상: 알고리즘 단위 검정 4개 + 실행별 2개(W2 DDPG s0, W2 TD3 s0).
- 귀무 모집단: 각 대상의 (정책, 기준선) 순수익 쌍에서 정책 열을 r′ = (r − μ_p) + μ_e·σ_p/σ_e로 바꿔 두 SR을 같게 만든다(알고리즘 단위는 시드·창별로 같은 변환).
- ΔG 귀무: log(1+r′) = log(1+r) − mean_p + mean_e (두 연율 로그 성장을 같게).
- 합성 표본: 정상 부트스트랩(Politis–Romano 1994) 평균 블록 10과 20 각각으로 크기 점검 1,000개(지표 ΔSR·ΔG 각각). 검정 블록(원형 b = 20)과 생성 방식을 일부러 다르게 둔다. 합성 표본 하나당 검정 B = 999.
- 경계 점검: Δ = +δ로 옮긴 모집단에서 비우월 규칙(단측 상한 < δ)의 기각률, Δ = −δ에서 하한 규칙(단측 하한 > −δ)의 기각률. 이항 오차를 크기 점검과 맞추려 생성 방식마다 **4,000개**. ΔG 경계는 지금(δ_G 고정), **ΔSR 경계는 δ_SR 커밋 후** 같은 코드로 한다(`calib_srb`).
- 판정(대상·지표·생성 방식마다): 크기 기각률 ∈ [0.03, 0.07] → 통과, < 0.03 → **보수적**, > 0.07 → **보정 실패**. 추가로 꼬리별 기각률(p < α이면서 θ̂ > 0, p < α이면서 θ̂ < 0)이 어느 쪽이든 **0.04**(0.025 + 약 2.9 이항 SE)를 넘으면 보정 실패(우위·열위는 방향 주장이므로). 경계 기각률 ∈ [0.6·α/4, 1.4·α/4] → 통과, 아래 → 보수적, 위 → 보정 실패.
- 처리: "보정 실패"인 대상·지표는 구간·범주를 "보정 실패"로 표시하고 기술 통계로만 쓴다. "보수적"은 범주를 유지하되 표에 표시한다. 보수적 검정이 어느 주장도 쉽게 만들지 않는다는 말은 꼬리별 크기 점검(우위·열위)과 경계 점검(비우월·동등)을 함께 통과했을 때만 성립한다. 두 생성 방식 중 하나라도 실패면 실패. 방법을 바꿔 다시 하지 않는다.
- 보정 점검은 b = 20에서만 한다. b = 5·10 결과와 점검 대상이 아닌 대상(창 단위·D·D′·E·나머지 실행별)에는 다른 점검 결과를 붙이지 않고 "보정 점검 대상 아님"으로 둔다.
