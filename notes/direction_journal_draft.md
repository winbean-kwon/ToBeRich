# 저널 투고 수준 방향 초안 (2026-10-27, 검토 전)

> 상태: 초안. 반박 검토 전. 사전 등록 아님.

## 0. 문제 진단 — v2가 왜 졸업논문 수준에 머무는가
v2의 주장 범위 제한 자체는 결함이 아니다(제한을 풀면 심사에서 무너진다). 수준을 낮추는 원인은 다음이다.
1. **질문이 작다.** "공식 코드가 설정 비용을 쓰는가"는 예/아니오 사실 확인이고, 확인된 실패는 계보 기준 2개다. 심사 반론: "무비용 결과는 2019 리뷰 이후 알려진 한계".
2. **영향 측정이 얕다.** FinRL 4 + AlphaMix+ 2 = 6개 비교, EarnMore는 축소판. 시드 5개 4/5 기준은 유의성 판정이 아님.
3. **세 점검이 서로 다른 데이터·정책에 흩어져 있다.** 시작 상태(자기 정책·EIIE), 비용(공개 코드), 분해(자기 사례 정책)가 하나의 결론으로 모이지 않는다.
4. **가장 강한 결과(시작 상태)는 평균 ≈0인 분산 효과**이고 공식은 EMA 과도 응답이다.

## 1. 제안: 하나의 질문으로 묶는 대규모 재평가
**질문:** "공식 코드가 있는 출판 RL 포트폴리오 방법들이, 검증된 하나의 평가 프로토콜(비용 실제 부과·시작 상태 통제·다중 평가 창·다중 시드·단순 베이스라인·다중 비교 통제) 아래서도 보고한 우위를 유지하는가? 유지되지 않는다면 어느 평가 조건이 그 차이를 만드는가?"

장르: 추천시스템의 Dacrema et al.(RecSys 2019, "Are we really making much progress?"), RL의 Henderson et al.(AAAI 2018), 자산가격의 Hou–Xue–Zhang(RFS 2020, "Replicating Anomalies")와 같은 대규모 재현·재평가.

### 구성
- **모집단(사전 고정):** 다자산 RL 포트폴리오 출판 논문 중 저자 공식 코드가 있는 것. 현재 조사 56편 중 코드 링크 15개 + 보충 검색. 목표 실행 가능 10개 내외. 실행 불가·데이터 비공개도 결과로 집계(Dacrema처럼 "재현 가능 비율").
- **프로토콜(점검 3가지가 여기서 도구가 됨):**
  - 비용: 참조 명세 대비 C1/C2 통과한 env만 사용, 미통과는 수정 후 사용(수정 전후 모두 보고).
  - 시작 상태: 워밍업 / 현금 / 등가중 시작 3종.
  - 평가 창: 원 논문 창 + 사전 고정한 롤링 창 여러 개(같은 데이터 원천).
  - 시드: 방법당 ≥5(가능하면 10).
  - 베이스라인: 매기 등가중(1/N, 비용 포함), buy-and-hold, 최소분산, 모멘텀 — DeMiguel–Garlappi–Uppal(2009) 기준.
  - 통계: 샤프 차이 검정(Ledoit–Wolf 2008), 블록 부트스트랩, 방법 전체에 대한 다중 비교(Hansen SPA 또는 Romano–Wolf).
- **1차 결과(사전 등록):** 원 논문 설정에서 보고 우위를 재현한 방법 수 → 통일 프로토콜에서 1/N 대비 우위가 유지되는 방법 수.
- **2차 결과:** 우위 상실을 조건별로 분해(비용 / 시작 상태 / 평가 창 / 시드). 기존의 반사실 분해·위약 검정은 여기서 "선택·타이밍 실력" 판정 도구로 재사용.
- 기존 결과의 위치: 시작 상태 공식 = 왜 짧은 단일 창 평가가 잡음이 큰지의 설명 장; 비용 감사 = 프로토콜의 env 검증 단계; 자기 사례(EarnHFT형) = 동기 사례.

### 범위 분리
- 졸업논문(12월 중순): 위 설계의 부분집합 — 실행 가능한 4~5개 방법(FinRL 4알고리즘, AlphaMix+, EIIE/PGPortfolio, DeepTrader 또는 MASA 등).
- 투고판(2027 상반기): 10개 내외로 확장, 2차 코더로 문헌 조사 재코딩.
- 목표 학술지(가설): TMLR, ICAIF 2027, Quantitative Finance, Journal of Financial Data Science, Expert Systems with Applications.

## 2. 내가 아는 위험
- Velay et al. 2023(DRL 포트폴리오 강건성 벤치마크), PRUDEX-Compass, TradeMaster, FinRL-Meta 벤치마크와 겹칠 수 있음 — 차별점이 "출판 방법의 공식 코드 + 보고 주장 대비 판정"이어야 함.
- 계산량: 1인, 무료 Colab CPU. 방법당 학습 시간 미확인.
- 결과가 "대부분 우위 유지"로 나오면 덜 흥미로움(그래도 보고).
- 공식 코드가 오래돼 실행 불가인 비율이 높을 수 있음.

## 3. 반박 검토 결과 (2026-10-27, 독립 에이전트)
판정: **조건부 추진, 초안 그대로는 하지 말 것.**
- 헤드라인 결론은 선행연구 있음: Kruthof & Müller, "Can deep reinforcement learning beat 1/N?", Finance Research Letters 75 (2025) — SAC를 DeMiguel 7개 데이터셋에 적용, 무비용에서도 1/N 체계적 우위 없음, 0.1% 비용에서 순수익 음수. 일반 SAC이지 출판 방법·공식 코드는 아님. Velay 2023, Lavko–Klein–Walther(EFMA 2023)도 일반 알고리즘.
- "출판 방법을 공식 코드로 재현 후 통일 프로토콜로 재평가"는 검색 범위(약 10회)에서 부재 → 남는 차별점.
- 실행 가능성: 코드 15개 중 사망·대체 4(SimplexDecomposition, Liang 2018, SBCA, ICAIF'20), 데이터 비공개 2(DeepTrader, MASA), TF1 등 구버전 4(PGPortfolio·원 데이터 소실, WaveCorr, RAT, jackieli19), 실행성 높음 약 5(FinRL, TradeMaster(재구현), AlphaMix+, EarnMore, DeepAries). 독립 계보 약 3. 보충 후보: Cross-Insight Trader, DeepClair, LSRE-CAAN(미검증).
- "10개 내외"와 Dacrema형 틀은 성립 안 함. FinRL 4개 알고리즘을 방법 4개로 세는 것은 부풀리기.
- 필요 조건: N=5~7로 정직하게 축소, 1차 결과를 "출판 주장 재현율 + 재현된 우위의 생존 비율"로 고정(Kruthof와 구분), 재현 성공 등급 기준 사전 등록, 비용 재학습·동일 튜닝 예산, MDE/동등성 검정.
- 게재: (a) 대부분 상실 → TMLR, FRL 단신, JFDS 시도 가능 / (b)(c) → TMLR·KCI·워크숍. ESWA·QF는 맞지 않음.
- 대안(덜 위험): 56편 조사를 2차 코더와 재코딩(κ 보고)한 보고 관행 메타연구 + 공식 코드 3~5개 재현·재평가.
- 졸업논문: 4~5개는 비현실적 → FinRL + AlphaMix+ + (DeepAries 또는 EarnMore) 3개, 축소 격자.
