# 사전 등록 — FinRL 비용 기울기 실험 확장: 수수료 1%와 위약 조건 (2026-11-27)

> 상태: 실행 전. 기반 `notes/finrl_costgrad_prereg.md`(808c2d6)와 결과 `notes/finrl_costgrad_result.md`. 스크립트 `replication/finrl_costgrad.py`(60c0989)를 확장한다. 결과를 보고 기준을 바꾸지 않는다.
> 지위: 우리가 손실을 바꾼 기제 실험. 공개 방법의 평가가 아니다.
> 동기(반박 심사 지적): (i) 0.25%에서 비용 항이 손실 기울기를 상대 0.34%만 바꿔 검정력이 낮았다, (ii) 위약 대조가 없어 원본의 현금 퇴화가 사라진 것을 비용 항에 귀속할 수 없었다.

## 1. 조건 (데이터·구조·시장·시드·학습 설정은 기반과 같다)
- **O1 / G1:** 원본 / 복원(기반 G와 같은 변경), 수수료 1%(env `comission_fee_pct` = 0.01). 12쌍.
- **P(위약):** 수수료 0.25%, 손실 = 원본 손실 + λ·mean(Σᵢ muᵢ²). λ는 비용과 무관한 섭동으로, 설정마다 학습 전 초기 정책·첫 학습 배치에서 매개변수 기울기의 상대 변화가 같은 설정 G(0.25%)의 관문 값과 같아지도록 정한다(이분 탐색, float64). 12개. O(0.25%)는 기반 결과를 그대로 쓴다.
- 관문: G1의 c=0.01 대 0 기울기 상대 차이(float64) > 1e-6; P의 λ 보정 오차 ≤ 10%.

## 2. 판정 (고정)
- **H-G1′(1% 관성):** α_eff(G1) < α_eff(O1) − 0.05 인 쌍 ≥ 9/12 → "1%에서는 관성이 커진다", ≤ 3 → "커지지 않았다", 그 밖 "엇갈렸다".
- **H-G2′(1% 회전율):** 회전율(G1) < 0.9 × 회전율(O1) 인 쌍 ≥ 9/12 → "줄었다", ≤ 3 → "줄지 않았다", 그 밖 "엇갈렸다".
- **H-P(위약, 퇴화 귀속):** 테스트 평균 노출 < 0.5인 설정 수: 기반 O 5/12, G 1/12. P가 ≤ 1/12이면 "위약도 같은 변화를 낸다 — 퇴화 감소는 비용 항에 특정되지 않는다", ≥ 4/12이면 "위약은 그 변화를 내지 않는다 — 비용 항 특정과 모순되지 않는다", 그 밖 "엇갈렸다".
- 보조: 각 조건의 회전율·노출·등가중 대비 초과(기술 통계).

## 3. 한계 (미리 적음)
- 1%는 현실보다 높은 비용이다(효과가 있는지 보는 값). 데모 하이퍼파라미터, 시드 3개.
- 위약은 하나의 섭동 형태다. "어떤 섭동이든"을 대표하지 않는다.
- α_eff의 노출 차원 한계(기반 결과 4장)는 그대로다.
