# 사례 간 표: 미기재·불일치 항목 (2026-11-15, Claude 정리, 탐색적)

> 각 결과 노트에 이미 적힌 사실만 모았다. 새 계산은 없다. **원인을 확정한 표가 아니다.** 어떤 항목도 단독 원인으로 분리하지 않았다(각 노트의 "원인 판정하지 않음" 그대로).
> 칸 표기: ● = 이 사례에서 해당 항목이 미기재이거나 우리 실행과 달랐다는 기록이 있음. ◐ = 기록은 있으나 결과에 영향이 없었거나 해석이 갈림. ○ = 관련 기록 없음 또는 해당 없음.
> 판정 등급은 사전 등록 판정 그대로다. 반박 심사 1회 반영(2026-11-15, 표시 12칸·§2 수정).

## 2. 기술(판정 아님)
- 7개 사례 모두에서 ●가 둘 이상이다. ● 수가 많은 항목은 (6) 데이터·종목 구성(6/7)과 (5) 하이퍼파라미터·학습 길이·임계값(5/7)이다. 다음은 (2) 실행 수·집계 방식(● 4, ◐ 1)이다. 사례가 7개이고 무작위 표본이 아니므로 이 빈도를 분야의 빈도로 읽지 않는다.
- (1) 보고 결과 선택 규칙은 4개 사례에서 기록됐다. AlphaMix+는 이 선택만으로 등급이 바뀐다.
- (8) 근접은 ρ를 측정한 2개 사례(DeepAries·FinRL)에서 관찰됐다. AlphaMix+는 가중치 기록만 있고 학습 뒤에는 1/N에서 벗어난다. 나머지 4개는 측정하지 않았다.
- 실행 수가 미기재인 사례에서 우리는 실행 방식을 따로 정했다. Ensemble·RAT는 시드 미고정 5회 평균, FinRL은 시드 0~4 중앙값, MARS는 고정 시드 10개 중앙값이다.
- 공개 시점 코드로 수치(R1)와 비교 주장(R2)이 함께 성립한 것은 FinRL의 PPO·TD3(알고리즘 단위)뿐이다. 통일 프로토콜(O2)에서는 FinRL의 우위가 유지되지 않았다(소실 2, 불확정 2). O2는 비교 대상(DJIA → 매일 등가중)과 비용(0 → 0.1%)을 함께 바꾼 조건이다.

## 3. 한계
