# 불일치 원인표 (2026-11-13 작성, 탐색적 — 판정 아님)

깊은 재현 6편의 결과에서 보고값과 차이가 난 부분을 기제별로 정리한다. 판정은 각 결과 노트의 사전 판정을 그대로 두고, 이 표로 바꾸지 않는다. 이 표는 사후 정리이므로 논문에서는 "exploratory"로 표시한다.

근거 유형:
- **개입 검증**: 그 요인만 바꾼 실행을 사전 등록하고 효과를 쟀다.
- **반사실 재계산**: 같은 원자료에 다른 정의를 적용했다. 새 실행은 없다.
- **코드 읽기**: 실행으로 확인하지 않았다.
- **추정**: 근거가 정황뿐이다.

어떤 기제로도 차이를 다 설명하지 못하면 "설명 안 됨"이라고 적는다.

## 1. 공통 기술 지표 (`replication/reproduction_synthesis.csv`, 탐색적 열)

이 표에서 읽을 수 있는 것:
- **보고값이 우리 시드 범위 안에 든 경우:** DeepAries, AlphaMix+ S2021·S2019, FinRL PPO·DDPG·TD3, MARS N. 이들에서는 "보고값이 여러 실행 중 좋은 쪽 하나와 같다"는 설명과 모순되지 않는다. 확인된 것은 아니다.
- **보고값이 범위 밖인 경우:**
  - 아래쪽(보고값이 더 높음): FinRL A2C, MARS L, Ensemble.
  - 위쪽(보고값이 더 낮음): RAT.
  - AlphaMix+ S2020은 범위 상한(12.27)보다 0.43 높아 사실상 경계다.
- **허용 폭과 실행 변동의 크기 차이:**
  - DeepAries: 허용 폭(±0.87)이 같은 코드의 환경 간 차이보다 훨씬 좁다. 선택된 시드 값이 맥 5.04, Colab 9.87로 4.8%p 차이다.
  - AlphaMix+ S2019: 허용 폭(±1.27)이 시드 범위(4.2)보다 좁다.
  - 이런 대상에서 "미재현"은 실행 잡음만으로도 나올 수 있다. 등급 정의의 한계로 논문에 적는다.

## 3. 대상 사이에 반복된 것 (탐색적, 6편 기준이라 일반화하지 않음)
1. **선택 규칙이 미기재이거나 결과에 영향을 줌:** DeepAries, AlphaMix+, MARS C, RAT. 시드·epoch·체크포인트를 고르는 규칙이 논문에 없거나 코드와 다르다. 규칙을 바꾸면 등급이 바뀐 경우가 있다(AlphaMix+, 반사실).
2. **집계·평가 정의가 미기재:** FinRL 집계 방식, DeepAries ^DJI 구간, MARS 평가 창, Ensemble 문턱.
3. **공개 코드가 논문 이후 바뀜:** MARS N, RAT README의 사전 학습 모델(이슈 제기 뒤 추가).
4. **허용 폭보다 큰 실행 간 변동:** DeepAries, AlphaMix+ S2019.

이 네 범주는 사후 분류다. 각 범주에 대한 주장은 해당 대상의 근거 유형을 넘지 않는다.
