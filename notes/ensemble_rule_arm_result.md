# 탐색적 — Ensemble F7 구간의 "등가중 + 같은 난류 현금 규칙"(RL 없음) 비교 (2026-11-27)

> 스크립트 `replication/ensemble_rule_arm.py`(규칙·문턱·지표를 머리에 고정하고 실행 전 커밋; JSON 직렬화만 수정), 결과 `replication/ensemble_rule_arm.json`. 규칙은 `notes/ensemble_postpub_prereg.md` 3장 (c)와 같다.
> 지위: 탐색적. 구간(2016-01-04~2020-05-12)은 F7·7.7에서 이미 본 구간이다. 판정이 아니다.

## 결과
| | Sharpe(1,097행) | 2020년 전(1,006행) |
|---|---|---|
| 등가중 + 난류 현금 규칙(RL 없음) | **1.185** | 1.344 |
| 등가중(같은 비용) | 0.436 | 1.021 |
| Ensemble E1–E5 | 1.176 · 1.017 · 1.012 · 0.992 · 0.845 (평균 1.008) | 1.242 · 1.078 · 1.078 · 1.049 · 0.895 |
- Ensemble이 규칙 포트폴리오보다 높은 실행: **0/5**(전 구간), 2020년 전도 0/5.
- 규칙 포트폴리오: 현금 일수 420/1,097, 누적 +56.9%, MDD −7.8%.

## 점검
- 난류 지수: 코드 `calcualte_price`·`calcualte_turbulence`를 그대로 불러 같은 번들 데이터로 계산한 값과 이 스크립트의 계산이 최대 6.4e-11 차이로 같다. 번들 `dow30_turbulence_index.csv`는 코드 계산과 다르다(최대 차이 121, 상관 0.997) — 코드는 이 파일을 쓰지 않고 실행 때 다시 계산하므로 비교에는 코드 계산값을 썼다.
- 문턱 일정은 코드와 같다(사이클 인덱스 기준 140 → 100 → 90).

## 해석 (냉정하게)
- 이 구간에서 같은 난류 현금 규칙을 등가중에 붙인 것만으로 Ensemble 다섯 실행 모두와 같거나 더 높은 Sharpe가 나왔다. 7.7의 "등가중 대비 우위는 현금 전환 구간에 몰려 있다"와 7.6의 "난류 규칙을 끄면 등가중보다 낮다"와 함께 읽으면, 이 코드의 위험 조정 성과는 RL 정책보다 하드코딩된 난류 규칙과 문턱에서 나왔다고 보는 것과 모순되지 않는다.
- 주의: 이미 본 구간, 사후 비교, 검정 없음. 문턱 일정(140/100/90)은 원 저자가 이 구간의 표본 안 분석으로 정한 값이라 규칙 포트폴리오도 같은 정보를 쓴다(공정한 비교이지만 표본 밖이 아니다). 출판 이후 구간의 사전 등록 검정은 WBA 데이터 문제로 미실행이다.
