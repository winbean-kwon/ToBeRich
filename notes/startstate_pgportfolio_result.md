# PGPortfolio 원조 학습된 관성·시작 상태 효과 — 결과: 실행 불가 (2026-11-28)

> 사전 등록 `notes/startstate_pgportfolio_prereg.md`(e5b124c). 대상 서버 `~/f4work/eiie_inspect/repo`(48cc5a4), 데이터 `~/f4work/Data.db`(sha256 e8a0da9e…, RAT 저자 공유 Crypto-A). 학습·측정은 하지 않았다.

## 1. 사전 판정
- **관문 G1 실패 → "실행 불가".** 사전 등록 1장대로 측정 없이 끝낸다. H-I·H-S는 판정하지 않는다.
- G1 기준: "Data.db가 기본 설정 기간·코인 선택에 필요한 30분 봉을 모두 포함한다". 기본 `net_config.json` 기간은 2015/07/01–2017/07/01이고, Data.db `History` 표는 1451577600(2016-01-01 00:00 UTC+8)부터 1514736000(2018-01-01)까지다(11종목, 2,126,983행).
- 코드의 close 질의와 같은 조건(`date+300`, 30분 격자, 시작·끝은 `parse_time` = 로컬 시간 `mktime`)으로 센 기본 기간 격자 35,089개 중 DB에 있는 비율(TZ Asia/Seoul·Asia/Shanghai·UTC 모두 소수 넷째 자리까지 같음):
  - BTS·DASH·ETH·LTC·STR·VTC·XMR·XRP·reversed_USDT: 결측 25.2%(2015-07-01–2015-12-31 전체 없음)
  - ZEC: 결측 66.5%(DB 시작 2016-10-28), STRAT: 결측 73.5%(DB 시작 2016-12-19)
- 관문 판단에 쓴 것은 DB 범위와 격자 개수뿐이다(읽기 전용 sqlite 질의). 학습·평가 지표는 보지 않았다.

## 2. 해석(냉정하게)
- 오프라인 모드에서 원 코드는 이 결측을 오류로 멈추지 않는다. `globaldatamatrix.py` 182행은 `min_date > start`일 때 온라인일 때만 앞부분을 받아오고, 178–180행의 "Have to be online" 예외는 끝 쪽 결측에만 걸린다. 결측은 118행 `panel_fillna(panel, "both")`(시간축 bfill 후 ffill)로 채워진다. 그래서 "코드의 데이터 매트릭스 생성이 온라인 조회 없이 끝남"은 아마 성립하겠지만(실행해 확인하지는 않음), 학습 구간의 약 1/4(ZEC·STRAT는 2/3 이상)이 평평한 가격으로 채워진 다른 데이터가 된다. 사전 등록의 G1은 "모두 포함"을 요구하므로 실패로 판정한다.
- 기간을 Data.db 범위로 바꾸면 돌릴 수는 있지만, 사전 등록은 기간을 코드 기본값으로 고정했다. 결과를 보기 전이라도 관문 실패 뒤 설정을 바꾸는 것은 이번 사전 등록 밖이다. 하려면 새 사전 등록이 필요하다.
- 따라서 "비용을 학습 신호로 보고 직전 가중치를 입력에 넣는 구현이 관성을 학습하는가"라는 질문은 이 구현에서도 답하지 못했다. 현재 측정된 것은 FinRL EIIE·EI3(5.5, α_eff 0.990–1.000)와 WaveCorr(α_eff 0.99993–0.999998, ΔSR 0, `notes/startstate_costaware_result.md`)뿐이고, 둘 다 관성을 학습하지 않았다. RAT(서버 디스크 하한으로 측정 못 함)와 PGPortfolio 원조(데이터 관문 실패)는 비어 있다. 이 공백 때문에 "비용을 보는 공개 구현은 관성을 학습하지 않는다"는 일반화는 할 수 없다.

## 3. 기록용 부가 확인(관문 G2·G3)
- G2(100스텝 학습 시험)는 G1 실패로 하지 않았다. 다만 환경 점검에서 다음을 확인했다(실행에 쓰지 않음): 서버 `adrl/p37`(TF 1.15.4, tflearn 0.5.0, numpy 1.16.4)은 Pillow가 없어 `import tflearn`이 실패하고(이전 감사는 import 스텁 사용), pandas 1.0.3이라 원 코드의 `pd.Panel`(globaldatamatrix.py 72행, data.py `panel_fillna`)이 동작하지 않는다(pandas 0.24.2는 `~/f4work/p37`·`wavecorr/p37`에만 있음). G1을 통과했더라도 G2에는 환경 우회(스텁·패키지 경로)가 필요했다.
- G3(직전 가중치 입력, 정적): `pgportfolio/learn/network.py` 102–108행(EIIE_Output_WithW: `previous_w`를 [B, 11, 1, 1]로 reshape해 특성 축에 concat한 뒤 1×1 합성곱으로 투표). 학습에서는 `nnagent.py` 170행(PVM의 직전 행 `last_w`), 백테스트에서는 `nnagent.py` 212행(`last_w[1:]`, BTC 제외)과 `trader.py` 91행·`backtest.py` 77행(직전 보유 = 비용·가격 변화 반영 뒤 가중치, 초기값 BTC 100% `trader.py` 42–43행). 관성 경로는 있다.
- 부가: Data.db에는 11종목만 있어 오프라인 코인 선택(거래량 상위 11)은 DB 전체가 된다. 원 논문 실험의 코인 구성과 같은지는 확인하지 않았다.
