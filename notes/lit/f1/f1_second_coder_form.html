F1 두 번째 판정 (15편)

판정 방법 (사전 등록 notes/f1_recheck_prereg.md)
  1. 논문 PDF에서 github, code, available, repository, supplementary, request를 검색한다.
  2. 학회 페이지의 supplementary를 본다.
  3. 1저자·교신저자의 GitHub와 개인 홈페이지를 본다.
  4. Hugging Face 논문 페이지를 본다.

앞 단계에서 공식 저장소(저자 본인·저자 조직의 계정이거나 논문이 가리키는 저장소, 오늘 열림)를 찾으면 거기서 멈추고 찾음. 찾음이 아닌 판정은 네 곳을 모두 본 뒤에만 적는다. 편당 상한 20분, 넘으면 그때까지의 판정을 적는다.

값: 찾음(URL·근거 위치 필수) · 제3자만(저자와 무관한 재구현만) · 링크 사망(논문이 가리키는 링크가 안 열림) · 요청 시 제공 · 없음 · 원문 미확보

입력은 이 브라우저에 자동 저장된다. 끝나면 'CSV 저장' → 터미널에서 python3 replication/f1_recheck_form.py import ~/Downloads/f1_second_coder_sheet.csv second
