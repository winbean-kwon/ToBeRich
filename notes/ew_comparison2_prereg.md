## (1) Margin Trader (탐색적 F7x, `notes/funnel_f7x_margintrader_result.md`)
- 쓰는 출력: 탐색적 F7x 실행의 시드별 시험 계좌 가치(서버 F7x 출력, 읽기만 하고 맥 scratchpad로 복사). 재학습 없음.
- 등가중: `notes/ew_comparison_prereg.md` 2장과 같은 규칙 — env가 쓰는 종목·같은 날짜·매일 등가중 재조정·현금 시작·비용률 c = env 설정값(`marginEnv.py`의 거래 비용률; 정적 확인 후 기록), 비용 0 등가중도 보고. 롱 전용 등가중이다(Margin Trader는 마진·공매도를 쓴다 — 비교 기준이 롱 전용임을 결과에 적는다).
- 지표: F7x 판정 스크립트의 Sharpe 식. 보고: 등가중(c) 초과 실행 수 k/n, 해석 문장은 `ew_comparison_prereg.md` 3장과 같은 기준(≥0.8 / ≤0.2 / 엇갈림).
