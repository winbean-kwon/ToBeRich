# 사전 등록 — 비용을 학습 신호로 보는 공개 코드(RAT, WaveCorr)의 학습된 관성과 평가 시작 상태 효과 (2026-11-27)

> 상태: 실행 전, 모델 존재 확인 전. 서버가 다른 실행(Ensemble 29종목 탐색판)을 마친 뒤에 시작한다.
> 동기: 5.5절 결론 — 시작 상태 효과는 정책의 관성에서 나오고, FinRL EIIE·EI3 공개 구현은 관성을 학습하지 않았다(비용 기울기 없음; 복원해도 0.25%에서 관성 없음). 7.1절 감사에서 RAT(손실 기울기 상대 차이 5.77)와 WaveCorr(9.52)는 학습 신호가 비용에 반응했다(S). 질문: 비용을 학습 신호로 보는 공개 구현은 관성을 학습하는가, 그리고 평가 시작 보유가 보고 지표를 실질적으로 바꾸는가.

## 1. 대상과 모델 (고정)
- RAT: 6장 F7 실행의 공식 코드·설정(서버 `~/f4work/RAT`, F7과 같은 환경). WaveCorr: F7x 실행의 공식 코드·설정(`~/f4work/wavecorr`).
- 모델: F7·F7x 실행에서 저장된 학습 완료 모델이 남아 있으면 그것을 쓴다(RAT는 코드가 선택한 체크포인트 P와 마지막 스텝 F 둘 다, WaveCorr는 마지막 에폭). 남아 있지 않으면 같은 설정으로 시드 3개를 다시 학습한다(RAT 대상당 상한 GPU 12시간, WaveCorr 상한 CPU 10시간; 넘으면 끝난 시드만 쓰고 기록).
- 두 구현 모두 정책 입력에 직전 가중치가 들어간다(RAT·WaveCorr 코드; 정적 확인을 실행 전 기록에 남긴다). 들어가지 않으면 그 대상은 "관성 경로 없음"으로 기록하고 측정하지 않는다.

## 2. 측정 (5.5 정의와 같음)
- α_eff: 학습(또는 검증) 구간 20개 시점에서 현금 시작과 등가중 시작으로 60스텝 실행(학습 없음), 노출 차이 누적이 Σ(1−α)^(k+1)과 같아지는 α. 현금 자산이 없는 구현이면 "현금" 대신 "직전 가중치 = 한 자산 집중"과 "등가중" 두 시작으로 하고 차원은 L1 가중치 거리로 정의한다(구현별로 실행 전 기록).
- 시작 상태 효과: 시험 구간에서 코드의 원래 시작 보유로 평가한 보고 지표(RAT fAPV·SR, WaveCorr SR)와, 시험 시작 전 60스텝 워밍업 후의 보유로 시작한 지표의 차이.

## 3. 판정 (고정; 단위 = 모델)
- **H-I(관성):** α_eff < 0.5인 모델이 대상별 모델의 절반 이상이면 "이 구현은 관성을 학습했다", 아니면 "학습하지 않았다".
- **H-S(시작 상태):** 대상별로 |지표(원래 시작) − 지표(워밍업 시작)|의 중앙값이 RAT fAPV 상대 5% 이상 또는 SR 0.1 이상, WaveCorr SR 0.1 이상이면 "보고 지표에 실질적 영향", 아니면 "실질적 영향 아님".
- 함께 보고: 5.5 FinRL 결과와의 대비. 두 가설 모두 기술적 판정이며 유의성 검정이 아니다.

## 4. 한계 (미리 적음)
- 대상 2개, 모델 수 적음. 시험 구간 정보가 들어간 체크포인트(RAT P)는 F와 나란히 보고한다.
- WaveCorr는 TF1 서버 환경, RAT는 GPU 서버 환경에 의존한다. 서버 C: 3GB 하한.
